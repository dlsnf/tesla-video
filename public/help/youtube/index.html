유튜브가 봇으로 볼 때

차 화면에서 읽고, 실제 저장은 맥 크롬에서 합니다

「봇이 아님을 확인하세요」나 「페이지를 새로고침해야 합니다」는 차가 아니라 서버가 유튜브에서 영상을 받아올 때 막힌 것입니다. 테슬라에 유튜브를 로그인해도 해결되지 않습니다.

  1. 1

    맥에서 크롬을 엽니다

    폰이나 테슬라가 아니라 맥(또는 PC) 크롬이어야 합니다. 테슬라에는 확장 프로그램이 없습니다.

  2. 2

    시크릿 창에서 youtube.com 로그인

    크롬에서 시크릿 창을 새로 열고 youtube.com 에 로그인합니다. 평소 쓰던 창에서 내보내면, 유튜브가 쿠키를 바로 바꿔서 「페이지를 새로고침해야 합니다」가 나옵니다.

  3. 3

    확장 설치

    크롬 웹스토어에서 Get cookies.txt LOCALLY 를 설치합니다. 다른 쿠키 확장도 Netscape 형식을 내보내면 됩니다.

  4. 4

    쿠키 복사 후 시크릿 창을 닫기

    그 시크릿 탭에서 확장 아이콘 → Export → Netscape 형식을 복사합니다. 맨 위가 # Netscape HTTP Cookie File 이고 youtube.com 이 들어 있어야 합니다. 복사한 뒤 시크릿 창을 바로 닫으세요. 그 창을 열어 두면 쿠키가 다시 바뀝니다.

  5. 5

    맥 크롬에서 연결 페이지 열기

    아래 버튼을 누르거나, 주소창에 사이트 주소 뒤 /tv/connect/ 를 붙여 엽니다. PIN 입력 후 복사한 텍스트를 붙여 넣고 저장하고 연결을 누릅니다.

    이 단계는 테슬라가 아니라 맥에서 해야 붙여넣기가 됩니다.

    쿠키 저장 페이지 열기
  6. 6

    차에서 다시 재생

    저장이 끝나면 차 브라우저를 새로고침한 뒤 같은 영상을 다시 엽니다. 그래도 안 되면 서버에서 docker compose up -d --build 한 다음 다시 시도합니다.

안 될 때

  • 「페이지를 새로고침해야 합니다」는 평소 크롬 창에서 내보낸 쿠키가 이미 바뀐 경우가 많습니다. 시크릿 창에서 다시 내보낸 뒤 그 창을 닫고 저장하세요.
  • 쿠키를 넣었는데도 같으면, 낡은 쿠키가 오히려 방해일 수 있습니다. 서버 data/youtube-cookies.txt 를 지우고 docker compose up -d --build 한 다음, 쿠키 없이 다시 재생해 보세요.
  • 쿠키를 저장한 뒤 유튜브에서 로그아웃하면 다시 막힙니다. 다시 2~5단계를 하세요.
  • FTP로 data/ 폴더를 통째로 올리면 쿠키 파일이 지워집니다. data/ 는 올리지 마세요.
  • 유튜브가 정책을 바꾸면 같은 안내가 또 나올 수 있습니다. 그때는 쿠키를 다시 넣으면 됩니다.
